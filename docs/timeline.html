open-airplay · open-airdrop-windows

Fifteen years of opening up AirPlay and AirDrop

These projects stand on public, open-source reverse-engineering work by many people. This page traces that work, from the first open AirTunes receiver in 2011 to the Windows app built on it in 2026.

At a glance

Each dot links to its entry below.

2011

  1. April 2011Receiver

    shairport

    James Laird

    An open AirTunes (RAOP) receiver that emulates an AirPort Express, built on keys recovered from the device's firmware. It let iTunes and iOS stream audio to ordinary computers with no Apple hardware in the middle.

2012

  1. March 2012Receiver

    ShairPlay

    Juho Vähä-Herttua and contributors

    A reusable AirPlay and RAOP server library. Much of the later open mirroring code, including RPiPlay's, grew from it.

2014

  1. April 2014Receiver

    shairport-sync

    Mike Brady

    A fork of shairport that keeps audio in sync across multiple rooms, and became the long-lived successor once shairport stopped being maintained.

2015

  1. April 2015Receiver

    playfair

    EstebanKubata

    A small GPL library that handles the FairPlay setup step a mirroring receiver must answer. RPiPlay and UxPlay both ship it.

2017

  1. February 2017Client

    pyatv

    Pierre Ståhl · pyatv.dev

    A Python client library for Apple TV and AirPlay devices: discovery, pairing, remote control and streaming, with thorough protocol documentation.

2018

  1. August 2018AWDL

    “One Billion Apples’ Secret Sauce”

    Milan Stute, David Kreitschmann, Matthias Hollick · SEEMOO Lab, TU Darmstadt

    A detailed public account of Apple Wireless Direct Link (AWDL), the previously undocumented Wi-Fi protocol under AirDrop and AirPlay, worked out from binary and runtime analysis. Presented at ACM MobiCom ’18 that autumn.

2019

  1. By early 2019Receiver

    AirplayServer

    dsafa22

    An AirPlay mirroring server for Android, built on ShairPlay. RPiPlay is a port of it. The original repository is no longer online; RPiPlay's README documents its role.

  2. May 2019Receiver

    RPiPlay

    FD-

    An open AirPlay screen-mirroring receiver for the Raspberry Pi, with a careful write-up of how the protocol changed over the years.

  3. May 2019AWDL

    OWL and OpenDrop

    SEEMOO Lab, TU Darmstadt · Milan Stute, Alexander Heinrich and colleagues

    Open Wireless Link, an open AWDL implementation in C, and OpenDrop, an open AirDrop implementation in Python. Together they brought AirDrop to Linux.

  4. August 2019AWDL

    “A Billion Open Interfaces for Eve and Mallory”

    Stute, Narain, Mariotto, Heinrich, Kreitschmann, Noubir, Hollick · USENIX Security ’19

    A security analysis of AWDL and AirDrop, including the Bluetooth LE trigger that wakes AirDrop, which open implementations rely on.

2020

  1. April 2020Receiver

    UxPlay

    antimof

    An AirPlay mirroring receiver for Unix desktops, built from the OpenMAX-based RPiPlay's code, rendering through GStreamer instead.

2021

  1. July 2021Receiver

    UxPlay moves to FDH2

    FDH2

    Active development continues in a new home, adding AirPlay audio-only streaming and HLS video, and running on Linux, macOS, BSD and Windows. It is the receiver engine open-airplay builds on.

  2. August 2021AirDrop

    PrivateDrop

    Heinrich, Hollick, Schneider, Stute, Weinert · USENIX Security ’21

    Found design flaws that let attackers learn the phone numbers and email addresses of AirDrop senders and receivers, and proposed a privacy-preserving fix with an open implementation.

2022

  1. October 2022Receiver

    shairport-sync 4.1 adds AirPlay 2

    Mike Brady and contributors

    Open-source AirPlay 2 audio playback, released as “Really Big Update — AirPlay 2!”.

2026

  1. April 2026Sender

    doubletake

    Omar Roth · omar.yt

    An open AirPlay screen-mirroring sender for Linux, with FairPlay SAP authentication, PIN pairing and an encrypted video stream that current Apple TVs accept. open-airplay's Windows → Apple TV mirroring is ported from it.

  2. July 2026Sender

    doubletake reimplements FairPlay SAP

    Omar Roth

    A reverse-engineered implementation replaces an earlier one that ran a carved-out piece of Apple's code under an ARM64 emulator. Releases from v0.4.0 (July 2026) are licensed LGPL-3.0-or-later; v0.3.2 and earlier were GPL-3.0-or-later. On provenance, see issue #59 and the note below.

  3. July 2026AWDL

    OWL for MediaTek

    Jed Blenkhorn

    A fork of OWL with monitor-mode workarounds so the built-in MediaTek MT7921 can do AirDrop without a separate USB adapter.

  4. September 2026AirDrop

    omdrop and omdrop-awdl

    Brent (brentkearney)

    AirDrop send and receive on Apple Silicon Macs running Omarchy (Linux), with AWDL support for their Broadcom BCM4387 Wi-Fi.

  5. October 2026AirDrop

    omdrop-owl

    Tristan (t4t5) · t4t5.com

    AirDrop in both directions on a MediaTek MT7925, as in the Framework 13, running OWL on the access point's own channel so Wi-Fi stays connected. The direct inspiration for open-airdrop-windows.

  6. October 2026This project

    open-airplay and open-airdrop-windows

    parsakhaz and contributors

    One Windows app for Apple interop: receive AirPlay on a PC, mirror the Windows desktop to an Apple TV with real FairPlay mirroring, and (in progress) AirDrop on the built-in Wi-Fi card. GPL-3.0.

How these dates were chosen. Each date is a public release, a paper's publication, or, where nothing earlier is documented, the creation date of the project's public repository. Work often began earlier than it was published. Every link points to the project's own repository, its authors' site, or the paper itself, checked in October 2026.

On FairPlay provenance. In doubletake issue #59, a user asked how its FairPlay SAP tables and constants were derived. The author answered that the current implementation is reverse-engineered and contains no Apple code other than the constants needed to interoperate with Apple's receivers. We have not audited this independently. FairPlay SAP authenticates a sender; it is not FairPlay Streaming DRM.

Not here? If we missed or misdescribed your work, please open an issue. SEEMOO's former project site, owlink.org, is no longer associated with OWL, so it isn't linked.
